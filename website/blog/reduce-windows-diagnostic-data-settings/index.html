How to Reduce Windows Diagnostic Data Collection: The Settings That Matter

2026-10-11 · sabaoongfx · 3 min read

Windows collects diagnostic data about how the system and its apps behave, and Microsoft documents that collection and lets you control part of it. This guide covers the settings most people mean when they ask how to turn telemetry down, and is upfront about what these switches can and can’t do. We aren’t privacy lawyers, and we aren’t claiming that Windows is doing something sinister. The goal is to help you make informed choices.

The two switches to start with

Open Settings > Privacy & security > Diagnostics & feedback. Reporting from PCWorld recommends turning off two options here:

  • Send optional diagnostic data. Windows separates data it describes as required from data it describes as optional. Turning the optional setting off limits what is sent to the required set.
  • Tailored experiences. This uses your diagnostic data to personalise tips and suggestions. Turning it off stops that personalisation.

Menu names and layout change between Windows versions, so if you don’t see exactly these labels, look for the same terms nearby and check Microsoft’s current documentation.

Things worth reviewing next

  • Activity history and advertising ID. Both sit in the Privacy & security section and are easy to switch off if you don’t use them.
  • App permissions. The same section lists which apps can use your location, camera, microphone and files. Many people have never opened it.
  • Optional features such as Recall. If your hardware offers them, read what they store before enabling. We discuss the reasoning in Windows Recall and the case for software you can audit.
  • Account type. A local account sends less to a cloud account than a Microsoft account, though it also loses sync features.

What these switches don’t do

Be realistic about the limits. Turning off optional diagnostic data reduces what is sent but does not stop all communication: Windows still checks for updates, and required diagnostic data continues. Home and Pro editions generally can’t reduce collection below the required level through the Settings app. Third-party apps have their own data practices that these settings don’t touch.

One more caution: some users report that updates re-enable settings they had switched off. That is a user report rather than something we have confirmed, but it is cheap to guard against. Re-open the page after major feature updates and confirm your choices held.

See what is actually running

Settings tell you what is permitted. A task manager tells you what is running. Open the Processes view and look through the list for background items you don’t recognise, then research a name before deciding anything. The Startup apps tab shows what launches with Windows. This won’t reveal network traffic on its own, and for that you need the approach in how to check what an app sends over the network.

A sensible stance

You don’t have to choose between ignoring privacy and abandoning your operating system. A reasonable middle path is to switch off the optional settings, review app permissions once a quarter, prefer software you can inspect for tools that watch your activity, and keep your system updated. Privacy is made of many small decisions, and none of them needs to be dramatic.
