Why Your Browser Uses So Much Memory, and What You Can Do About It

2026-10-11 · sabaoongfx · 3 min read

Open a task manager and the biggest line on your list is almost certainly your web browser. It is such a common sight that people assume something is wrong. Usually nothing is. Browsers are among the most complex programs you run, and the memory they use is largely a deliberate trade for speed, stability and security. Still, there is plenty you can control.

Why browsers use many processes

Modern browsers split their work across processes: a main browser process, separate processes for web pages, a GPU process, a network service, and one per extension in some designs. The reasons are good ones. A crashing tab shouldn’t take down the others, and keeping sites in separate processes makes it harder for a malicious page to read another page’s data. That isolation costs memory, because each process carries its own copy of some runtime data.

What a tab really costs

Tabs differ enormously. A static article might need a few dozen megabytes; a web app such as a spreadsheet, video editor or social feed can need hundreds. Pages hold images, scripts, a layout tree and often a large JavaScript heap. Background tabs keep most of that unless the browser discards them.

Extensions add their own overhead, and some inject code into every page you visit. A dozen extensions can add more memory than a dozen idle tabs.

Reading the numbers correctly

Because the browser is many processes, you must look at the total, not one row. Use a grouped Processes view so all helpers add up under the browser’s name. Be aware that resident memory counts shared pages in each process, so the sum can overstate the true cost (why). Browsers also include their own task manager, usually under a “more tools” menu, that shows memory per tab and per extension. Use it to find the heavy pages.

Ways to reduce it

  1. Close tabs you aren’t using. Bookmark or use a reading list instead of keeping 60 pages open as a to-do list.
  2. Turn on tab discarding. Most major browsers have an option that unloads inactive tabs and reloads them when you click. Check your browser’s performance settings.
  3. Audit extensions. Disable them all, then re-enable only those you need. Remove the rest.
  4. Watch for heavy sites. Pages with autoplay video, live feeds and web apps are the biggest. Use the browser’s own task manager to name them.
  5. Restart the browser occasionally. Long sessions accumulate memory. Most browsers restore your tabs.
  6. Keep it updated. Memory improvements and leak fixes arrive regularly.

When high usage is a good thing

If you have plenty of free RAM, a browser that caches aggressively is doing you a favour: pages reopen instantly. High memory use only becomes a problem when it crowds out other programs or pushes the system into swapping. Check the Performance chart before you start closing things. If memory is nowhere near full, there is nothing to fix.

A note on desktop apps built on browsers

Many desktop programs, including chat clients and note-taking tools, are web pages in disguise and carry their own browser engine, so each one is another full browser in memory.
