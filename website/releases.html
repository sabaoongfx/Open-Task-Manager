What's new

Every version of Open Task Manager and its terminal UI, otm, newest first. Downloads, checksums and the full commit history are on GitHub Releases.

0.4.0

September 27, 2026 Latest

See what's filling your disk: a new Disk usage tab in the style of WinDirStat.

New

  • Disk usage tab. Opening it scans your home folder right away. You get a folder tree sorted biggest first, the space and file count for each file type, and a treemap that shows every file as a tile sized by how much space it takes. Click a tile to find that file in the tree.
  • Pick a drive or type any path to scan something else. Right-click a folder to scan just that folder, show it in your file manager, or copy its path.
  • Sizes match du: space actually used on disk, hard links counted once, and the scan stays on one drive. It's read-only and never deletes anything.
  • otm gets the same tab (press 8). It scans the folder you started otm in; o scans the selected folder and Backspace scans the parent.

Improved

  • Every Linux package now includes AppStream metadata, so software centers show a proper description and screenshots.
  • Download links that always point at the newest version, for every installer and every otm archive.
  • The otm tab bar squeezes to fit narrower terminals instead of cutting off tabs.

0.3.0

September 24, 2026

A terminal version of the app, and Linux repositories you can install from.

New

  • otm, a terminal UI with the same seven tabs and the same data as the desktop app: grouped processes, filtering, sorting, end task with a confirmation, Braille graphs, and mouse support. Handy over SSH or on servers.
  • Signed apt and pacman repositories, so Linux installs update like any other package. Every Linux package installs both the desktop app and otm.
  • Standalone otm downloads for Linux, Windows and macOS.

Changed

  • The package is now called open-task-manager (it was task-manager) and replaces the old one on upgrade.

0.2.0

September 15, 2026

Every tab from the Windows 11 Task Manager, backed by real data wherever the OS provides it.

New

  • Details: a sortable flat list of every process with its status and owning user.
  • Users: processes grouped by account, with live CPU, memory and disk totals per user.
  • Startup apps: your real autostart entries.
  • Services: the real systemd service list.
  • App history: CPU time per app since the app was opened.
  • Right-click menus on every table.

Fixed

  • Installed Linux builds showed a generic icon in the taskbar instead of the app's logo.
  • Tables could scroll sideways when they shouldn't.
