Animated SVG generator

Make a looping animation with no code: floating bubbles, pulse rings, orbits or a morphing blob. Download it as a self-contained animated SVG, or record it as a video. Everything happens in your browser.

How to use the Animated SVG Generator

  1. Pick an animation style and set the amount and speed.
  2. Choose a palette and press Randomize for a new composition.
  3. Click Download SVG for a single animated file that loops forever, or Copy SVG to paste the code.
  4. To get a video, choose a length and size and click Record video. Keep the tab open while it records.

What it is good for

  • Animated backgrounds and loaders for websites, using only an img tag or inline SVG.
  • Lightweight motion for landing pages that avoids heavy video files.
  • Looping visuals for streams, presentations and social posts, via the video export.
  • Learning how SVG animation works by reading the generated code.

Frequently asked questions

How does the SVG animate without JavaScript or CSS?

The animation is written into the SVG file itself using SMIL elements such as animate and animateTransform. Browsers play it on their own, including when the file is used in an img tag.

Can I get a video or GIF?

The Record video button saves a WebM file in Chrome and Firefox, and an MP4 in Safari. GIF is not supported. To convert WebM to MP4 or GIF, use a tool such as ffmpeg.

Why did my recording stall?

The recording runs in real time, so a browser that pauses a background tab can pause the animation too. Keep the tab visible until it finishes.

Does the animated SVG work everywhere?

It plays in current Chrome, Edge, Firefox and Safari. Some editors and image viewers show only the first frame, because they do not implement SVG animation.

Is my data sent anywhere?

No. The animation and the video are created on your device.
