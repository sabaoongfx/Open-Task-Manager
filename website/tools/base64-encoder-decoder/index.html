Base64 encoder and decoder

Convert text to Base64 and back instantly. It handles emoji and non-English text correctly, and can produce URL-safe Base64 without padding.

How to use the Base64 Encoder and Decoder

  1. Choose Encode or Decode.
  2. Type or paste into the Input box. The result updates as you type.
  3. Turn on URL-safe if the result goes into a URL or a JWT.
  4. Use Swap to feed the output back in, or Copy output.

What it is good for

  • Reading Base64 values in API responses, config files and emails.
  • Embedding small text or data in JSON, HTML or CSS.
  • Preparing HTTP Basic auth style values for testing.
  • Inspecting the parts of a JWT, which use URL-safe Base64.

Frequently asked questions

What is Base64?

A way to write binary or text data using only 64 safe characters (letters, digits, plus and slash). It makes data safe to put in text formats, but it is not encryption.

Is Base64 secure?

No. Anyone can decode it, so never use it to hide secrets.

Does it support emoji and accented letters?

Yes. Text is converted to UTF-8 bytes before encoding, and decoded the same way, so all Unicode text round-trips correctly.

What is URL-safe Base64?

A variant that replaces + with - and / with _, and drops the = padding, so the value can sit in a URL or filename without escaping.
