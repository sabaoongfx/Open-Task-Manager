CSS box shadow generator

Tune a box-shadow with sliders and see it update live. Start from a preset such as subtle, layered, hard or glow, then copy the CSS.

How to use the CSS Box Shadow Generator

  1. Pick a preset or move the offset, blur and spread sliders.
  2. Set the shadow colour and opacity. Soft shadows usually use black at 10 to 30 percent.
  3. Use the page and box colours to preview it on your own background.
  4. Click Copy CSS and paste the box-shadow line into your stylesheet.

What it is good for

  • Cards, buttons, modals and dropdowns that need depth.
  • Glow effects for focus states and highlighted items.
  • Inset shadows for pressed buttons and input fields.
  • Checking how a shadow looks on light and dark backgrounds.

Frequently asked questions

What do the box-shadow values mean?

In order: horizontal offset, vertical offset, blur radius, spread radius and colour. The optional inset keyword draws the shadow inside the box.

What does spread do?

Positive spread grows the shadow beyond the box, negative spread shrinks it. A negative spread with a larger blur gives a soft, realistic lift.

Can I layer several shadows?

Yes, in CSS you can list several shadows separated by commas. Copy the output and add more by hand for layered effects.

Do shadows affect performance?

Large blurs on many animated elements can be costly. For ordinary static cards the cost is negligible.
