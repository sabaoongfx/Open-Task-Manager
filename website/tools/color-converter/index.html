How to use the Color Converter

  1. Type or paste a color such as #1a73e8, rgb(26 115 232) or tomato, or use the picker.
  2. Read the HEX, RGB, HSL, HSV and CMYK values and click Copy next to the one you need.
  3. Check the contrast rows: WCAG AA needs at least 4.5:1 for normal text.

What it is good for

  • Moving a brand color between design tools and CSS.
  • Finding the HSL values to build lighter and darker shades.
  • Checking whether text on a background meets accessibility guidelines.
  • Turning a named CSS color into HEX.

Frequently asked questions

Which formats can I type in?

HEX (3, 4, 6 or 8 digits), rgb() and rgba(), hsl() and hsla(), and CSS color names such as rebeccapurple. Your browser does the parsing.

Is the CMYK value exact?

No. CMYK here is a simple mathematical conversion from RGB, useful as a starting point. Print profiles use colour management, so check printed results with your printer.

What do the contrast ratios mean?

WCAG asks for at least 4.5:1 for normal text (AA) and 7:1 for the stricter AAA level. Large text needs 3:1 for AA.

Does it keep transparency?

Yes. If you enter an alpha value, the HEX output gains two extra digits and the RGB output becomes rgba().
