Why these run in your browser

Every tool here is plain JavaScript that runs on your device. The images, text and files you work with are processed locally, so nothing you enter is uploaded, logged or stored. They keep working on a slow connection once the page has loaded.

These tools come from the Open Task Manager project, a free, open-source task manager and system monitor for Linux, Windows and macOS.
