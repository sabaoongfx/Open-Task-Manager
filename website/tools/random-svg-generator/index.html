Random SVG generator

Scatter random blobs, circles, rings, polygons and rounded squares into a clean vector image. Tweak the palette and count, then copy the SVG code or download it as SVG or PNG. It runs entirely in your browser.

How to use the Random SVG Generator

  1. Pick a shape type, or leave it on Mixed, and set how many shapes you want.
  2. Choose a palette and a dark, light or transparent background.
  3. Press Randomize until you like the result. Each press gives a new seed.
  4. Use Copy SVG to paste the markup into your project, or download the file as SVG or PNG.

What it is good for

  • Placeholder artwork and hero backgrounds for prototypes and landing pages.
  • Avatars, cover images and social cards that need a unique abstract graphic.
  • Texture and pattern ideas for design exploration, opened afterwards in Figma, Illustrator or Inkscape.
  • Generative art experiments: the same seed always gives the same image.

Frequently asked questions

What is a random SVG generator?

It is a tool that builds a scalable vector graphic from randomly placed shapes. Because the output is SVG, it stays sharp at any size and can be edited in any vector editor or by hand in a text editor.

Is it free, and does it upload my images?

It is free and there is no account. The image is created by JavaScript on your own device, and nothing is sent to a server.

What do I do with the seed?

The seed is the code behind the randomness. Keep a seed and your settings and you will get exactly the same image again. Change the seed, or press Randomize, for a new one.

Can I use the images commercially?

The tool does not add any licence or watermark and claims no rights over what it generates. You made the image, so you decide how to use it.

Can I edit the result afterwards?

Yes. Download the SVG and open it in Figma, Illustrator, Inkscape or a code editor. Every shape is a plain path, circle, rectangle or polygon element.
