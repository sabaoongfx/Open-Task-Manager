SVG to PNG converter

Turn any SVG into a crisp PNG at the size you choose. Paste the code or open a file, set a scale or an exact width, optionally add a background colour, and download. The conversion happens on your device.

How to use the SVG to PNG Converter

  1. Paste your SVG code into the box, or click Open SVG file.
  2. Choose a scale (2x is good for sharp screens) or type an exact width in pixels.
  3. Turn on Fill background if you need a solid colour instead of transparency.
  4. Press Download PNG.

What it is good for

  • Making PNG logos and icons for places that don't accept SVG, such as some email clients and social networks.
  • Exporting favicons, app icons and Open Graph images at exact sizes.
  • Rasterising generated SVG art, charts and diagrams for slides and documents.
  • Checking how an SVG renders in a browser.

Frequently asked questions

Is my SVG uploaded anywhere?

No. The SVG is drawn onto a canvas by your browser and saved as a PNG on your device.

Why is my PNG blurry?

A PNG has a fixed number of pixels. Increase the scale or enter a larger exact width. The SVG itself never loses sharpness.

Does it keep transparency?

Yes, by default the background stays transparent. Turn on Fill background to add a solid colour.

Why did my SVG fail to render?

SVGs that load external images, fonts or stylesheets can't be drawn to a canvas for security reasons. Inline those resources, or convert text to paths in your editor first.

What is the largest size I can export?

Browsers limit canvas size, so the tool caps width at 16,000 pixels. Very large images can still run out of memory on phones.
