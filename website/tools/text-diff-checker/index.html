Text diff checker

Paste two versions of a text, config or piece of code and see exactly which lines were added or removed. Nothing is uploaded, so it is safe for private files.

How to use the Text Diff Checker

  1. Paste the original text on the left and the changed text on the right.
  2. Added lines are green with a plus sign, removed lines are red with a minus.
  3. Use the options to ignore whitespace or letter case.

What it is good for

  • Comparing two versions of a config file or document.
  • Spotting what changed between two API responses.
  • Checking edits before committing or sending them.
  • Comparing exported lists or logs.

Frequently asked questions

How does it compare the texts?

It compares line by line using a longest-common-subsequence algorithm, the same idea behind the Unix diff tool, so unchanged lines are matched up even when text moves around.

Is there a size limit?

Very large inputs with little in common can be too heavy for a browser. The tool tells you when to compare smaller sections.

Does it highlight changes inside a line?

No, it works on whole lines. A changed line shows as one removed line and one added line.

Is my text uploaded?

No. The comparison is done in your browser.
