UUID generator

Create one or hundreds of UUIDs at once. Pick random version 4, or version 7 that sorts by creation time, and copy the list. Values come from your browser's cryptographically secure random generator.

How to use the UUID Generator

  1. Choose version 4 or version 7 and how many UUIDs you need (up to 500).
  2. Optionally remove the hyphens or switch to uppercase.
  3. Press Generate, then Copy all.

What it is good for

  • Test data and fixtures for databases and APIs.
  • Unique IDs for records, files and sessions.
  • Time-sortable IDs (v7) for database keys that index well.
  • Placeholders while you design a schema.

Frequently asked questions

What is the difference between UUID v4 and v7?

Version 4 is almost entirely random. Version 7 starts with a millisecond timestamp followed by random bits, so IDs created later sort later, which is friendlier to database indexes.

Can two UUIDs collide?

With 122 random bits in a v4 UUID, the chance of an accidental collision is negligible in practice.

Are they generated securely?

Yes. The tool uses crypto.getRandomValues, the same source browsers use for cryptography.

Are UUIDs secret?

Don't rely on them as secrets. They are identifiers, and v7 even reveals when it was created.
